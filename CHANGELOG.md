# Changelog

## 2.3.0 — Public Release

### Release hardening
- Added Settings & Save screen.
- Added JSON save export/import for manual cross-device backups without accounts.
- Added confirmed local-progress reset.
- Sound and reduced-motion preferences now persist.
- The game automatically pauses when the tab/app loses focus.
- Reduced-motion mode disables camera shake/parallax and lowers large particle bursts without changing physics.
- Added startup recovery UI for module/runtime failures.
- Added a hard cap on transient particles for longer-session stability.
- Improved Web Audio resume behavior after mobile/browser suspension.
- Added 192px/512px app icons and Apple touch icon.
- Expanded installable web manifest and public metadata.
- Added no-stale-cache release headers and extra response hardening.
- Added 250-level procedural smoke tests and save portability tests.
- Added GitHub Actions QA workflow using Node 24.

### Gameplay carried forward
- Infinite deterministic skies and procedural archetypes.
- Themed world regions and milestone special levels.
- Checkpoints, five cloud types and automatic gate progression.
- Golden/Aurora Prism rewards and permanent rare-prism perks.
- Lightning, hail, rain-curtain and storm-spark obstacles.
- Prism chains, Rainbow Surge, Rainbow Rings and Sky Circuit bonuses.
- Rainbow Drops economy, auras, trails and three-star scoring.
